## 📥 Installation

1. Download the latest APK from [Releases](https://github.com/RahadHack99/iqoo-z9x-vivo-t3x-ghostlock/releases)
2. Install on your device
3. Open the app
4. Tap "Install" to root your device
5. Wait for the process to complete
6. Install KernelSU Manager when prompted
